Product Specification

Tech Stack Advisor

An AI-powered lead capture system that delivers real value upfront — helping prospects choose the right tech stack while converting them into warm, high-intent leads for 23 Systems.
1

Vision & Strategy

Traditional lead capture is a dead form on a landing page. Nobody wants to fill out "Tell us about your project" into a textarea and wait for a sales email. The Tech Stack Advisor flips this — prospects get an immediate, personalized consultation from an AI solutions architect, and 23 Systems gets a qualified lead with full project context.

Why This Works
  • Value-first exchange — the prospect gets a genuinely useful tech stack recommendation before we ask for anything
  • Natural qualification — the conversation itself reveals budget, timeline, team size, and technical maturity
  • High-intent leads — someone who completes a 5-minute AI consultation is far more engaged than someone who fills out a form
  • Conversation as data — the full chat history gives our sales team complete context before the first human call
  • Partner revenue — matching prospects with cloud credits, startup programs, and implementation partners creates a referral revenue channel

Question Architecture

The conversation engine uses an adaptive flow — the agent picks the next best question based on what it's already learned. No fixed sequence. Questions are skipped if the answer was already revealed in a prior response.

Tone: Consultative Expert

Like talking to a senior solutions architect having a real conversation. Professional, insightful, occasionally drops quick tips between questions. Example: "Good call on wanting real-time — that narrows things down significantly."

Phase 1: Opening (Always)
1
"Tell me about your project — what are you building and what problem does it solve?"
This single open-ended question often reveals 2-3 dimensions at once (type, audience, complexity)
Phase 2: Depth Selection (Always, asked 2nd)
2
"Would you prefer a high-level recommendation (3-4 more questions, ~2 minutes) or a deep dive (8-10 more questions, ~5 minutes)? The deep dive covers team dynamics, integrations, compliance, and budget."
Agent adapts remaining flow based on this choice — respects the prospect's time
Phase 3: Core Discovery (Adaptive)

High-Level Path — 3-4 questions from this pool:

3
"Is this an MVP/proof of concept, or are you building for production scale?"
4
"What's your team look like — solo dev, small team, or enterprise?"
5
"Any hard constraints? (existing infra, language preferences, compliance needs)"
6
"What's your timeline — weeks, months, or ongoing?"

Deep Dive Path — all of the above, plus adaptive selections from:

+
"What does your current tech stack look like, if any?"
+
"Do you need real-time features (chat, live updates, collaboration)?"
+
"What's your expected user load at launch? In 12 months?"
+
"Any third-party integrations you already know you'll need? (payments, auth, APIs)"
+
"What's your budget range for infrastructure? (bootstrapped, seed-funded, enterprise)"
+
"Does your industry have compliance requirements? (HIPAA, SOC2, PCI, GDPR)"
+
"How important is developer experience vs. raw performance?"
+
"Do you have a preference between managed services (Vercel, Supabase) vs. self-hosted?"
Adaptive Probing: The agent can also ask follow-up probes based on answers. For example, if the prospect mentions "real-time," the agent might ask about expected concurrent connections. If they mention "compliance," it digs into which specific regulations.
Phase 4: Summary & Confirmation (Always)

Before generating recommendations, the agent summarizes everything it's learned in a structured recap and asks the prospect to confirm or correct:

S
"Based on everything you've shared, here's what I'm working with: [structured summary]. Sound right before I build your recommendation?"
User confirms or corrects — agent proceeds to recommendation
Phase 5: Recommendation + Partner Question (Always)

Agent delivers the high-level stack recommendation (free preview), then asks:

P
"Based on your recommended stack, there are companies that offer free credits, startup programs, and implementation partners that could help bring this to life. Would you like me to include those in your full report?"
Natural conversational question, not a modal or CTA. Yes → partners included in report. No → report without partner section. Either way, lead gate follows.

Hybrid Architecture: State Machine + LLM

The discovery phase uses a zero-cost client-side state machine. The LLM is only called once — after lead capture. This makes the system nearly free to operate and immune to bot abuse.

PhaseEngineLLM CallsCost
Phases 1-4 (Questions + Summary)Client-side state machine0$0.00
Phase 5 (Recommendation)Single LLM call1~$0.01-0.05
Research validationbrave-search0~$0.003
Report generationTemplate population0-1~$0.02-0.05
Cost per qualified lead: ~$0.03-0.10. At 1,000 leads/month, total LLM cost is $30-100/month. The LLM only fires after email capture, so bots that don't submit a real email cost exactly $0.
Client-Side State Machine (Phases 1-4)

All discovery questions are pre-written and served from a conversation-tree.json file. The browser handles:

  • Conversation tree — each node has a message, expected input type, branching logic, and next-node mapping
  • Simulated typing — 500-1500ms delay before showing each message (feels like AI)
  • Conditional skipping — if an answer was already revealed in a prior response, skip that question
  • Structured data capture — free-text answers stored in a projectProfile object
  • Two variants — simple (business language) and dev (technical language) question sets
  • Zero server calls — runs entirely in the browser during discovery

Adapted from Clusters/lib/chat/components/ — stripped down: no sidebar, no history, no file uploads. Auto-scrolling + typing indicators reused from existing messages.jsx.

Lead Gate Modal

After the state machine completes Phase 4 (summary confirmation):

  1. Show a preview based on collected answers (no LLM — template-based summary)
  2. Modal overlay: "Enter your name and email to get your full Tech Stack Report"
  3. Form includes: Cloudflare Turnstile + honeypot field + email validation
  4. On submit: single LLM call for recommendations + store lead + fire CRM webhook
  5. Confirmation: "Your report is being generated. Check your email in ~5 minutes."
  6. Calendar widget appears: "Want to discuss this with our team?"
Middleware Update Required: The middleware.js auth check must be updated to exclude /consult and /api/consult from authentication. These routes must be fully public.

Build Phases

Four phases, each independently testable. The skill is the foundation — everything else builds on it.

Phase 1 — Foundation
Skill + Report Template
Deliverables: tech-stack-advisor skill, branded HTML report template, partners.json

Build the core intelligence: question framework, recommendation logic, report generation. Testable immediately from internal chat.

  • Create skills/tech-stack-advisor/SKILL.md with full question architecture
  • Create skills/tech-stack-advisor/partners.json with initial partner list
  • Create references/SOP Templates/tech-stack-report.html branded template
  • Create skills/tech-stack-advisor/generate-report.js report generation
  • Activate skill: symlink into skills/active/
  • Test: run full conversation from internal chat, verify report output
Phase 2 — Pipeline
Team Template + Multi-Agent Workflow
Deliverables: tech-consultation.json template, 3-role cluster pipeline

Wire up the Discovery → Research → Report pipeline as a team template. Testable via the portal UI.

  • Create config/templates/tech-consultation.json with 3 roles
  • Configure shared workspace data flow between roles
  • Test: deploy template from portal, verify all 3 roles execute and produce output
Phase 3 — Public Experience
Landing Page + Public Chat + Lead Gate
Deliverables: /consult page, /api/consult endpoint, lead gate modal

The net-new frontend work. Build the public-facing experience that turns visitors into leads.

  • Create app/consult/page.js — public landing page with hero + chat
  • Create app/api/consult/route.js — public streaming endpoint with rate limiting
  • Update middleware.js — exclude /consult from auth
  • Build lead gate modal component
  • Add Calendly/Cal.com embed for consultation booking
  • Test: visit /consult without login, complete full flow
Phase 4 — Growth
Lead Storage + CRM + Email Delivery
Deliverables: leads table, CRM webhook, email integration

Connect the lead capture to storage and sales workflows.

  • Add leads table to Drizzle schema + auto-migration
  • Configure CRM webhook in config/TRIGGERS.json
  • Set up email delivery (SendGrid/Resend webhook for report delivery)
  • Test: submit lead, verify SQLite + CRM + email all fire correctly
Verification Checklist
  1. Skill test: Run tech-stack-advisor from internal chat — verify question flow and report generation
  2. Template test: Create team from tech-consultation template via portal — verify all 3 roles execute
  3. Public page test: Visit /consult without logging in — verify chat loads, streams, and lead gate triggers
  4. Lead capture test: Submit lead form — verify SQLite entry AND CRM webhook fire
  5. Report test: Confirm branded HTML report generates with all sections populated
  6. Rate limiting test: Verify public endpoint respects rate limits
  7. End-to-end: Full flow from landing → conversation → gate → report delivery → calendar booking
Existing Infrastructure Leveraged: Chat streaming (SSE), brand-config.css theming, SOP template patterns, cluster orchestration, brave-search skill, Drizzle ORM + SQLite, webhook triggers. The only truly new code is the public page, the public API endpoint, and the lead gate modal.
