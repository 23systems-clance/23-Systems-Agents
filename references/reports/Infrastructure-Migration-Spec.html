Infrastructure Specification

Multi-Tenant Infrastructure Migration

Replacing GitHub Actions with Kubernetes + local LLM inference for SOC 2-compliant, cost-efficient agent execution at scale.
1

Executive Summary

The current 23WF architecture uses GitHub Actions to orchestrate Docker agent containers. This works for single-tenant usage but hits hard limits for multi-tenant production: 20 concurrent job cap, 30-60s cold starts, no tenant isolation, and linear cost scaling.

This spec defines a two-phase migration:

  • Phase 0 — Mac Mini M4 (16GB): Build and validate the new architecture locally. Run the event handler, job queue, and local LLM inference on a single Mac Mini. Agent execution stays on Claude Sonnet via API. Target: 1-10 tenants, 20-50 tasks/month.
  • Phase 1 — GKE Autopilot: Migrate to Google Kubernetes Engine when demand exceeds Mac Mini capacity. Same architecture, swapping Docker Desktop for managed K8s. Target: 10-100+ tenants, 100-1,000+ tasks/month.
Key outcome: Per-run cost drops from ~$0.26 (all-cloud) to ~$0.15 (hybrid with local LLM), with the ability to scale to thousands of concurrent tenants without architectural changes.

Target Architecture

The architecture replaces GitHub Actions as the orchestration layer while keeping the existing Docker agent image unchanged. Git is retained for code artifacts (PRs, commits) but decoupled from job scheduling.

Phase 0: Mac Mini (Development & Early Production)
Tenant Request (Web UI / API / Telegram) | v Next.js Event Handler (Mac Mini, port 3000) | v BullMQ Queue (Redis on Mac Mini) | v Worker Process (Mac Mini, Docker Desktop) | +---> Agent Container (your existing Docker image) | | | +---> Claude Sonnet API (coding/reasoning) | +---> Git push + PR (results) | +---> Ollama (Mac Mini, port 11434) | +---> Mistral Small 24B (job planning, chat) +---> Phi-4 14B (summaries)
Phase 1: GKE (Production Scale)
Tenant Request (Web UI / API / Telegram) | v Next.js Event Handler (Cloud Run or GKE pod) | v BullMQ Queue (Redis / Memorystore) | v K8s Job Controller (GKE Autopilot) | +---> namespace: tenant-abc (quota: 4 CPU, 8GB) | +---> Agent Pod (same Docker image) | +---> Claude Sonnet API | +---> Git push + PR | +---> namespace: tenant-xyz (quota: 8 CPU, 16GB) | +---> Agent Pod | +---> Agent Pod (concurrent) | +---> Ollama Pod or Mac Mini via Tailscale +---> Mistral Small 24B +---> Phi-4 14B
Key insight: Your existing Docker agent image does not change. You are only replacing how a container gets scheduled and isolated. The migration is an orchestration swap, not a rewrite.

Hybrid Model Routing

The architecture uses four LLM touchpoints. Only one — agent execution — requires a frontier model. The other three are routed to local models running on the Mac Mini via Ollama.

Touchpoint Complexity Model Rationale
Job Planning Medium Mistral Small 24B (local) Structured decision-making, small context window. Quality is sufficient.
Agent Execution High Claude Sonnet (API) Coding, multi-step reasoning, tool use. No local model matches quality.
Job Summary Low Phi-4 14B (local) Straightforward summarization. Phi-4 is fast and MIT-licensed.
Chat UI Medium Mistral Small 24B (local) Conversational Q&A. Cloud fallback for complex requests.
Fallback Strategy

If the Mac Mini goes offline or is under heavy load, all local LLM calls fall back to Claude Haiku via API. This adds ~$0.01-0.02 per affected call but ensures zero downtime.

// Routing pseudocode (event handler)
async function routeLLM(task, prompt) {
  if (task === 'agent_execution') {
    return callClaude('sonnet', prompt);
  }

  try {
    const model = task === 'summary' ? 'phi4:14b' : 'mistral-small:24b';
    return await callOllama(model, prompt, { timeout: 10000 });
  } catch (err) {
    // Fallback to cloud if local is unavailable
    return callClaude('haiku', prompt);
  }
}

Migration Phases

Phase 0 — Week 1-2
Mac Mini Setup & Local Orchestration
Hardware: $599 | Monthly: ~$3-10 | Effort: 1-2 weeks
  1. Purchase and set up Mac Mini M4 (16GB)
  2. Install Docker Desktop (or OrbStack), Redis, Ollama
  3. Pull Mistral Small 24B (Q4_K_M) and Phi-4 14B (Q5_K_M) via Ollama
  4. Set up Cloudflare Tunnel or Tailscale for external access
  5. Add BullMQ job queue to the event handler — replace GitHub Actions trigger with queue-based dispatch
  6. Add worker process that pulls from BullMQ, spawns Docker containers locally
  7. Wire LLM routing: planning/summaries to Ollama, agent execution to Claude Sonnet API
  8. Test end-to-end: web UI → queue → local container → Claude API → Git PR
Phase 0.5 — Week 3-4
Multi-Tenant Foundations
No additional cost | Effort: 1-2 weeks
  1. Add tenant isolation to the job queue (per-tenant queues or priority)
  2. Add per-tenant rate limiting in BullMQ
  3. Migrate from SQLite to Postgres for multi-tenant data
  4. Add tenant-scoped API keys and authentication
  5. Add job logging and per-tenant metrics
  6. Validate with 2-5 beta tenants
Phase 1 — When Needed
GKE Migration
Monthly: ~$144-180 | Effort: 1-2 weeks
  1. Create GKE Autopilot cluster on GCP
  2. Deploy Redis (Memorystore) and Postgres (Cloud SQL)
  3. Deploy event handler to Cloud Run or GKE pod
  4. Create K8s Job manifests for agent pods (reuse existing Docker image)
  5. Set up per-tenant namespaces, resource quotas, and network policies
  6. Connect Mac Mini via Tailscale for local LLM inference
  7. Configure monitoring (Prometheus + Grafana)
  8. Cut over: point DNS, migrate database, decommission Mac Mini as primary host
Phase 1.5 — Optional
Cloud Run Jobs (Lower-Cost Intermediate)
Monthly: ~$0-38 | Effort: 1 week
  1. Deploy event handler to Cloud Run
  2. Configure Cloud Run Jobs for agent container execution
  3. Use Upstash Redis (serverless, free tier) instead of Memorystore
  4. Skip GKE entirely until tenant isolation requirements demand it

This path gives you cloud hosting with near-zero idle cost, at the expense of K8s-level tenant isolation. Recommended if SOC 2 audit timeline is >6 months away.

Risk & Mitigation

Risk Severity Likelihood Mitigation
Mac Mini goes offline (power, network) High Medium LLM routing falls back to Claude Haiku API. Agent execution is already cloud-based. Only planning/summaries are affected.
16GB RAM insufficient for concurrent local LLM + Docker Medium Medium Ollama swaps models automatically. Docker containers share remaining RAM. Monitor with htop. Upgrade to M4 Pro 24GB if needed ($1,399).
Mistral Small quality too low for planning Low Low Planning is a structured task (routing decisions). Few-shot prompting with 2-3 examples closes most quality gaps. Fallback to Claude Haiku if needed.
GKE migration takes longer than expected Low Medium Mac Mini can serve 1-10 tenants indefinitely. GKE migration is not blocking. Cloud Run Jobs is a simpler intermediate step.
SOC 2 auditor rejects Mac Mini as production Medium Low Mac Mini only runs local LLM inference (no tenant data processing). Agent execution and tenant data are on GKE/Cloud Run. Document the split clearly.
Claude API cost spikes Medium Low Per-tenant rate limits in BullMQ. Max tokens cap per job. Smart routing to Haiku for simple tasks.

Decision Log

Decision Chosen Rejected Rationale
Start on Mac Mini vs cloud Mac Mini M4 (16GB) GKE from day one $599 one-time vs $144/mo idle. Validates architecture with real tenants before committing to cloud spend.
Local LLM for planning Mistral Small 24B Qwen 2.5 Coder 32B SOC 2 compliance requires US/EU model provenance. Qwen (Alibaba, China) adds audit friction. Mistral is 15% lower quality but sufficient for planning tasks.
Local LLM for summaries Phi-4 14B Mistral Small 24B Phi-4 is faster, smaller, and purpose-fit for summarization. MIT license (Microsoft). Frees RAM for other processes.
Agent execution model Claude Sonnet (cloud) Local model No local model matches Claude's quality for multi-step coding and tool use. This is where quality directly impacts product value.
Job queue BullMQ + Redis SQS, Cloud Tasks, RabbitMQ BullMQ runs locally on Mac Mini and on cloud. Same code, no vendor lock-in. Rich job lifecycle (delayed, retries, priority).
Cloud provider Google Cloud (GKE) AWS (EKS), Azure (AKS) Best managed K8s (Autopilot), aggressive spot pricing, strong AI ecosystem. Cloud Run Jobs as intermediate step.
Tunnel for Mac Mini Cloudflare Tunnel + Tailscale Port forwarding, ngrok Cloudflare Tunnel is free and production-grade. Tailscale for GKE-to-Mac Mini private link (WireGuard).
Knowledge distillation (Qwen → Mistral) Not worth it Distill Qwen outputs into Mistral Legally gray, 3-5% quality gain for weeks of engineering. Few-shot prompting gives 10-15% gain for free.
Total cost to start: $599 hardware (one-time) + ~$5.80/mo at 20 tasks/month. Idle cost: ~$2.60/mo. This is the cheapest path to validate a multi-tenant agent platform before investing in cloud infrastructure.
