System Overview

The Power Dialer is a browser-based, professional-grade calling system integrated into your Admin Dashboard. It automates sequential dialing, detects voicemails instantly, records and transcribes calls, and syncs every interaction to HubSpot CRM automatically. No desk phone or software download is required.

Key Capabilities

  • Automated sequential dialing: 40+ dials per hour (vs. ~15 manual)
  • Voicemail detection with 2-second auto-skip (90%+ accuracy)
  • Browser-based WebRTC calling — no phone hardware needed
  • Local presence dialing — caller ID matches the prospect's area code for 2-3x higher pickup rates
  • Automatic call recording and AI-powered transcription (Deepgram Nova-2)
  • One-click HubSpot CRM sync with call notes, disposition, recording, and transcript
  • Manager coach mode (listen-only) and barge-in capability on live calls
  • TCPA-compliant time-of-day enforcement and two-party consent disclosures
  • Real-time analytics: rep performance, list performance, when-to-call heatmaps
  • Callback scheduling with automatic reminder notifications

How It Fits Your Workflow

The Power Dialer is designed for outbound BDR campaigns. After your list has been enriched through the Slack bot (using BuiltWith + Apollo), contacts with phone numbers are loaded into campaign queues. BDRs open the dialer in their browser, start a session, and the system handles the rest — dialing, detecting voicemails, recording conversations, and logging everything to HubSpot.

Important
Only ONE active session is allowed per BDR at a time. The system runs exclusively on AWS — never run it locally.

Getting Started

Prerequisites

RequirementDetails
BrowserGoogle Chrome (recommended) or Firefox. Safari is NOT supported for WebRTC.
MicrophoneUSB headset or built-in mic. Bluetooth headsets may have latency issues.
InternetStable broadband connection. Minimum 5 Mbps up/down recommended.
PermissionsBrowser must allow microphone access for the Admin Dashboard domain.
AccountActive BDR account with dialer permissions in the Admin Dashboard.

Launching the Dialer

  1. Log into the Admin Dashboard at your organization's URL.
  2. Navigate to BDR > Dialer from the sidebar menu.
  3. The Pre-Call Check screen will appear automatically.

Pre-Call Check (Runs Every Session)

Before any session starts, the system verifies your audio setup and network connectivity.

  1. Microphone Check: Select your input device from the dropdown. Click ‘Test Mic’ to see the volume meter respond.
  2. Speaker Check: Select your output device. A test tone will play to confirm audio output.
  3. Network Check: The system tests WebRTC connectivity to Twilio's servers. A green checkmark confirms readiness.
  4. Click ‘Start Session’ when all three checks pass (green indicators).
Tip
Your mic/speaker selection is saved between sessions. You only need to re-select if you change devices.
Warning
If the network check fails, check your internet connection and ensure your firewall/VPN allows WebRTC traffic. Contact IT if the issue persists.

Power Dialing Workflow

Starting Your Dial Session

  1. After pre-call check, your contact queue loads automatically from the assigned campaign.
  2. The queue sidebar shows all callable contacts in priority order. Callbacks appear at the top.
  3. Click the ‘Dial’ button (or the system auto-dials if auto-advance is enabled).
  4. The system selects a local presence caller ID matching the contact's area code.
  5. You'll hear ringing through your headset while the contact's phone rings.

When a Human Answers

  1. The voicemail detector confirms a human answered (takes ~2 seconds).
  2. A connected-call timer starts (default: 45 seconds). This confirms it's a real conversation, not a brief voicemail greeting.
  3. Once the timer threshold is met, recording starts automatically. You'll see a red ‘REC’ indicator.
  4. Conduct your call. Use the Mute and Hold buttons as needed.
  5. When the call ends (either party hangs up), the Disposition Modal appears.

Call Controls

ButtonFunctionNotes
DialInitiates call to next contact in queueDisabled during active calls
HangupEnds the current callOpens disposition modal
MuteToggles your microphone on/offContact cannot hear you while muted

Session Auto-End

Sessions automatically end after 30 minutes of inactivity (no calls made). A warning notification appears at the 25-minute mark with a 5-minute countdown. If you're still active, simply make a call or click ‘Stay Active’ to reset the timer.

04

Voicemail Detection & Auto-Skip

The Power Dialer uses Twilio's Answering Machine Detection (AMD) to automatically identify voicemail greetings and skip them within 2 seconds. This is the primary productivity driver — eliminating the time BDRs spend listening to voicemail recordings.

How It Works

  1. When a call is placed, AMD runs in the background analyzing audio patterns.
  2. AMD classifies the answer within 2-4 seconds as one of: Human, Machine, Fax, or Unknown.
  3. If Machine or Fax: the call auto-terminates, logs as ‘Voicemail - Auto Skipped’, and the system advances to the next contact.
  4. If Human: the call continues to you normally.
  5. If Unknown: the system defaults to Human (you hear the audio and decide).

What You'll See

  • When voicemail is detected, a brief ‘Voicemail Detected’ indicator flashes on screen.
  • The system automatically moves to the next contact within 3 seconds.
  • No action is required from you — the skip is fully automatic.
  • Auto-skipped calls are logged in HubSpot as ‘No Answer’ (no recording attached).
Accuracy
AMD achieves ~94% accuracy for human detection and ~80-85% for machine detection. If AMD is uncertain, it defaults to treating the call as human-answered so you never miss a live prospect.

Call Dispositions

After every call (except auto-skipped voicemails), a Disposition Modal appears. You MUST select a disposition before the system advances to the next contact. Accurate dispositions are critical for campaign reporting and CRM data quality.

Disposition Types

DispositionWhen to UseCRM Outcome
Connected - InterestedProspect expressed interest; wants to learn more or book a meetingConnected
Connected - Not InterestedHad a conversation but prospect is not interestedConnected
Connected - Callback RequestedProspect asked you to call back at a specific timeConnected
Voicemail - Left MessageYou reached voicemail and left a message manuallyNo Answer
Wrong NumberNumber does not belong to the intended contactWrong Number
Do Not CallProspect explicitly asked to not be called againNo Answer
Invalid NumberNumber is disconnected, out of service, or not a real numberNo Answer

Disposition Workflow

  1. Call ends — Disposition Modal appears automatically.
  2. Select the appropriate disposition from the options above.
  3. Add notes in the free-text field (describe the conversation, next steps, objections, etc.).
  4. If ‘Callback Requested’: a date/time picker appears to schedule the callback.
  5. Click ‘Submit’ — the system syncs to HubSpot and advances to the next contact.
Critical
Selecting ‘Do Not Call’ adds the phone number to the global opt-out list permanently. This blocks the number across ALL campaigns for ALL BDRs. Only select this when the prospect explicitly requests it.
Note
‘Connected - Interested’ with meeting notes in the disposition counts as a ‘Meeting’ in analytics. Be sure to include meeting details when applicable.

Queue Management

Queue Structure

Your contact queue has two sections visible in the sidebar:

  • Callable Section: Contacts eligible for dialing, shown in priority order. Scheduled callbacks appear at the top.
  • Uncallable Section (collapsed by default): Contacts blocked from dialing with a reason badge.

Uncallable Reasons

ReasonDescriptionCan BDR Re-Add?
DNC (Do Not Call)Contact opted out of calls — permanent blockNo (admin only)
Removed ProspectBDR removed from queue — temporaryYes (with confirmation)
Invalid NumberAuto-detected by Twilio error on previous dialNo
No PhoneHubSpot refresh found no valid phone numberNo
TCPA BlockedOutside legal calling window (8 AM - 9 PM in contact's timezone)Auto-resolves

Queue Actions

  • Skip Contact: Moves the current contact to the end of your queue.
  • Re-add Prospect: For ‘Removed’ contacts only. Click the ‘Re-add’ button next to their name in the Uncallable section.
  • Refresh from HubSpot: Click the refresh icon in the queue header to re-sync contact data (phone numbers, job titles) from HubSpot.

Queue Persistence

Your queue state is saved on the server. If your browser refreshes, your internet drops, or you pause and resume your session later, the queue picks up exactly where you left off. No contacts are lost.

Callbacks & Follow-Ups

Scheduling a Callback

  1. During disposition, select ‘Connected - Callback Requested’.
  2. A date/time picker appears. Select the date and time the prospect requested.
  3. Add any notes (e.g., “Call after 2pm, ask about Q3 budget”).
  4. Submit the disposition. The callback is now scheduled.

Callback Reminders

When a callback is due:

  • A toast notification appears: “Callback due: [Contact Name] - [Company]”
  • Click ‘Call back now’ to immediately dial the contact (jumps to top of queue).
  • If you're on another call, the callback contact is inserted at position 2 (next after your current call).

Missed Callbacks

  • If a callback is not completed within 30 minutes of the scheduled time, it is marked as ‘Missed’.
  • Missed callbacks remain in your queue with a ‘Missed Callback’ badge.
  • When you start a new session, all due/overdue callbacks are loaded at the top of your queue.

Callback Priority Rules

  • Callbacks ALWAYS take priority over regular queue contacts.
  • If a contact is in both the callback queue and regular queue, the callback supersedes — the regular queue item is skipped.
  • Callback-to-connect rates are tracked separately from cold dial metrics in analytics.
Best Practice
Always honor callback times. A prospect who requested a callback is warm — missing the window significantly reduces your conversion rate.
08

Call Recording & Transcription

When Recording Starts

Recording does NOT start the moment a call connects. It begins only after the connected-call timer threshold is met (default: 45 seconds). This prevents recording brief voicemail greetings that AMD classified as human.

  • A red ‘REC’ indicator appears on screen when recording is active.
  • Both your voice and the contact's voice are recorded.
  • Recordings are stored securely on AWS S3 (not on your computer).

Transcription

All recorded calls are automatically transcribed using Deepgram Nova-2 AI. Transcripts are typically available within 5 minutes of call completion.

  • Transcripts include speaker labels (BDR vs. Contact) and timestamps.
  • Transcripts are synced to HubSpot as part of the call engagement.
  • Managers can review transcripts in the Recording Library.

Transcript Format Example

[0:15] BDR (Sarah): Hello, this is Sarah from Dev Labs. Am I speaking with John?
[0:23] Contact (John): Hi Sarah, yes this is John. How can I help?
[0:30] BDR (Sarah): Great! I'm calling because we noticed your company...

HubSpot CRM Sync

  • Dispositioned calls are synced to HubSpot within 60 seconds.
  • A recording link is embedded in the HubSpot call engagement — CRM users can play it inline.
  • The transcript is attached to the call body field, with speaker labels and timestamps.
  • If the transcript isn't ready when the engagement is first created, it is backfilled automatically once available.

Compliance & Safety

Legal Requirement
All compliance rules are enforced automatically by the system. However, BDRs must understand these rules to ensure proper conduct and respond appropriately to prospect requests.

TCPA Time-of-Day Enforcement

Federal TCPA regulations prohibit outbound calls before 8:00 AM or after 9:00 PM in the contact's local timezone. The system automatically enforces this.

  • Contacts outside the calling window are moved to the Uncallable section with reason ‘TCPA Blocked’.
  • These contacts automatically return to the Callable section when their time window opens.
  • The system uses area code-to-timezone mapping to determine local time.

Two-Party Consent States

In certain states, both parties must be informed that the call is being recorded. The system handles this automatically.

  • States requiring consent: CA, CT, FL, IL, MD, MA, MI, MT, NH, PA, WA
  • When calling a number in these states, an automated disclosure plays before you're connected:
"This call is being recorded for quality assurance purposes."

Do Not Call (DNC) Management

  • When a prospect says “Do not call me again,” you MUST select the ‘Do Not Call’ disposition.
  • This adds their phone number to the global opt-out list permanently.
  • DNC applies across ALL campaigns and ALL BDRs — the number is blocked company-wide.
  • Only administrators can remove a DNC entry (BDRs cannot).
  • DNC is keyed by phone number. If multiple contacts share a number, all are blocked.

24-Hour Cooldown Warning

If a contact was called within the last 24 hours (by any BDR, in any campaign), the system displays a warning. You can override this and proceed, but use good judgment to avoid harassing prospects.

Manager: Coach & Barge

Managers can silently monitor live BDR calls (Coach Mode) and optionally join the conversation (Barge Mode). This feature is available from both the Salesfloor Dashboard and the Active Calls page.

Coach Mode (Listen Only)

  1. Navigate to Salesfloor or Management > Active Calls.
  2. Find the BDR's active call card and click ‘Listen’.
  3. Your browser connects to the call via WebRTC (you'll need microphone permission).
  4. You can hear BOTH the BDR and the contact speaking.
  5. Neither the BDR nor the contact can hear you. You are completely silent.
  6. When the call ends, your connection terminates automatically.

Barge-In Mode

  1. While in Coach Mode, click the ‘Barge In’ button.
  2. Your microphone is unmuted — both the BDR AND the contact can now hear you.
  3. Use this to assist with difficult conversations, objection handling, or to close deals.
  4. You can return to Coach Mode by clicking ‘Mute’ (listen-only again).
Best Practice
Use Coach Mode regularly for training purposes. Save Barge-In for situations where the BDR clearly needs help or a deal is at risk. Frequent barging can undermine BDR confidence.

  1. Open Admin Dashboard and navigate to BDR > Dialer
  2. Complete pre-call check (mic, speaker, network)
  3. Start session — queue loads automatically

  5. Disposition every call accurately with notes
